# Horizon HUD

Forza Horizon 的游戏内覆盖 HUD，用于显示换挡灯、档位等信息。目前仅支持 Windows。

默认监听地址：`127.0.0.1:9999`

## 使用方法

1. 从 [Releases](https://github.com/Need-an-AwP/horizon-hud-gpui/releases) 下载最新版本，或自行编译后运行 `horizon-hud-gpui.exe`。
2. 按下面的步骤在游戏中开启数据输出。
3. 启动本程序，确认托盘图标已出现。设置窗口概览页中「遥测监听」应为「正在监听」。
4. 进入游戏后，用**非电动车**完成一次校准：同时按住**手刹 + 油门**，等转速拉高后松开。校准成功后换挡灯才会按当前车辆转速范围显示。
5. 之后即可正常使用。右键托盘图标可打开设置、切换「仅游戏时显示 / 图表显示」，或退出程序。

程序会记住外观与监听设置。配置文件为 `horizon-hud.toml`，优先放在可执行文件同目录。

## 游戏内配置

在 **Forza Horizon** 中：

1. 打开 **设置**
2. 进入 **抬头显示与游戏**
3. 滚动到最底部
4. 将 **数据输出** 设为开启
5. 填写地址和端口，与本程序默认值保持一致：
   - 地址：`127.0.0.1`
   - 端口：`9999`

若在 Horizon HUD 设置里改过监听地址或端口，游戏里也要改成相同的值。

## 从源码编译

需要安装 [Rust](https://rustup.rs/)（edition 2024）以及 Windows SDK。

```bash
cargo run
```

`cargo run` 以标准的console程序运行，以便展示输出。GitHub Release 中的构建产物以 Windows 子系统运行，不带有控制台窗口。
