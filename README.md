# Horizon HUD

Forza Horizon 的游戏内覆盖 HUD，用于显示换挡灯、档位等信息。目前仅支持 Windows。

默认监听地址：`127.0.0.1:9999`

## 使用方法

1. 从 [Releases](https://github.com/Need-an-AwP/horizon-hud-gpui/releases) 下载最新版本，或自行编译后运行 `horizon-hud-gpui.exe`。
2. 按下面的步骤在游戏中开启数据输出。
3. 启动本程序，确认托盘图标已出现。设置窗口概览页中「遥测监听」应为「正在监听」。同时只能运行一个实例；再次启动会打开已有实例的设置窗口。
4. 进入游戏后，用**非电动车**完成一次校准：按住**油门**拉到断油转速。校准成功后换挡灯才会按当前车辆转速范围显示。若在设置中开启「更严格校准条件」，则需同时按住**手刹 + 油门**。
5. 默认会把该车的断油转速写入配置。之后再开同一辆车会自动恢复，无需重校。概览页校准卡片在已有记录时会显示重置按钮，可清除当前车辆的记录后重新校准。
6. 之后即可正常使用。右键托盘图标可打开设置、切换「仅游戏时显示 / 图表显示」，或退出程序。

程序会记住外观、监听地址，以及已校准车辆的断油转速。配置文件为 `horizon-hud.toml`，优先放在可执行文件同目录。可在设置的**校准**页关闭「记住已校准车辆」：关闭后不再读取或写入车辆记录，已有条目会保留。电动车无需校准，直接使用遥测中的最大转速。

## 游戏内配置

在 **Forza Horizon** 中：

1. 打开 **设置**
2. 进入 **抬头显示与游戏**
3. 滚动到最底部
4. 将 **数据输出** 设为开启
5. 填写地址和端口，与本程序默认值保持一致：
   - 地址：`127.0.0.1`
   - 端口：`9999`

若在 Horizon HUD 设置里改过监听地址或端口，游戏里也要改成相同的值。

## 配置随游戏自动启动

在steam中找到极限竞速：地平线6，右键打开属性，在启动选项中填写：
```bat
cmd /c start "" "C:\Path\To\horizon-hud-gpui.exe" & %command%
```
请修改为自己的horizon-hud文件路径，注意使用英文双引号和反斜杠。最简单的办法，右键你的`horizon-hud-gpui.exe`文件，复制文件地址，或者ctrl+shift+c，即可得到标准的路径。
完成配置后horizon-hud即可自动跟随游戏启动。

## 从源码编译

需要安装 [Rust](https://rustup.rs/)（edition 2024）以及 Windows SDK。

```bash
cargo run
```

`cargo run` 以标准的console程序运行，以便展示输出。GitHub Release 中的构建产物以 Windows 子系统运行，不带有控制台窗口。
